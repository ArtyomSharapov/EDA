# EDA: Анализ данных 

Проект по разведочному анализу временных рядов с 183 датчиков за период 20.05.2021 — 25.01.2023. Включает очистку данных, оценку качества, приведение к единой временной шкале, анализ сезонности, тренда и корреляций. Полные результаты — в отчёте.

## Архитектура

**`data/`** — данные и результаты:
- `data.csv`, `info.csv` — исходные данные
- `clean_data.csv` — очищенные данные (153 датчика, 543 914 строк)
- `data_resampled_1h.csv` — данные с часовой детализацией (509 877 строк)
- `correlation_matrix.csv`, `v1_v2_correlation.csv` — результаты корреляционного анализа
- `*.png` — графики

**`src/`** — скрипты анализа (запускать по порядку):
- `volume.py` — объём данных по датчикам
- `rate_data.py` — оценка качества (пропуски, аномалии, выбросы)
- `date+detatilation.py` — определение периода и детализации
- `new_time.py` — приведение к единой временной шкале (resample)
- `correlation.py` — корреляционный анализ

## Итоги

- После очистки: **153 датчика, 543 914 строк** (удалён Type 4 из-за системного артефакта и одна аномалия).
- Данные приведены к часовой сетке: **509 877 строк, 0% пропусков**.
- Суточной и недельной сезонности нет; тренд слабый положительный.
- Средняя корреляция между датчиками — **0.46**; 5.1% пар с `r > 0.9`.
- 153 `idMeasure` фактически представляют **51 физический канал** (по 3 подканала).
